## 自己跑一遍

前提是你已经起了一个实例（见 [快速开始](../../QUICKSTART.md)），并且把 `examples/.env` 填好。

```bash
# 1. 新闻播报 —— 只换了音色别名
bash examples/curl/tts.sh "据本台消息，长三角一体化发展再提速。今天上午，沪苏湖高铁全线开通运营，沿线十二座古城被纳入一小时通勤圈。总台记者发回现场报道。" \
  --voice yun -o news_yun.mp3

# 2. 直播带货
bash examples/curl/tts.sh "家人们看过来！这款空气炸锅真的绝了，不用放油，二十分钟，薯条鸡翅外酥里嫩！今天直播间直降一百二，还送烤盘，三、二、一，上链接，手慢真的无！" \
  --voice lin -o livestream_lin.mp3

# 3. 古风诗词
bash examples/curl/tts.sh "明月几时有？把酒问青天。不知天上宫阙，今夕是何年。我欲乘风归去，又恐琼楼玉宇，高处不胜寒。起舞弄清影，何似在人间。" \
  --voice pangge -o poetry_pangge.mp3

# 4. 悬疑旁白
bash examples/curl/tts.sh "那扇门，已经三年没有开过了。可就在昨夜，楼下的邻居说，他听见里面有脚步声，一步，一步，很慢，正朝着楼梯口，越来越近。" \
  --voice evan -o suspense_evan.mp3

# 5. 情绪骤变
bash examples/curl/tts.sh "宝宝别怕，妈妈在……妈妈在这儿呢。你给我起来！作业又没写是不是？！对不起，妈妈不是故意凶你的。妈妈只是……太累了。" \
  --voice lin -o emotion_lin.mp3
```

> **重跑不会字节级一致。** 情绪、停顿、语速是模型根据文本推断的，
> 温度一变结果就变；而且这 6 段来自早期批次，当时的具体 `stability` /
> `similarity_boost` 没有留档。要点是**听同一段文本在你这台实例上能做到什么程度**，
> 不是去比对波形。

想批量对比不同参数，用 [`examples/python/batch.py`](../python/batch.py) 循环提交即可；
长文用 [`examples/python/long_text_job.py`](../python/long_text_job.py) 走异步任务。

## 这些音频能随便用吗

- **来源**：ElevenLabs 合成，脚本为本项目自写样例文案，不含任何客户素材。
- **许可**：随本仓库以 [Apache-2.0](../../LICENSE) 提供，可自由转发、用于评估与对内演示。
- **体积**：全部 128 kbps 单声道 mp3，共约 1.6 MB —— 这点体积是有意控制的。
  想加新的演示音频，见下节。

## 往这里加音频的规矩

`scripts/release_check.py` 只放行这一个目录下的音频，并且会检查：

| 约束 | 值 | 为什么 |
|---|---|---|
| 单文件 | ≤ 800 KB | 超过说明码率或时长失控，仓库会变重 |
| 合计 | ≤ 4 MB | 克隆成本 |
| 必须登记 | 出现在本 README 的表格里 | 否则半年后没人知道这段是谁、为什么在仓库里 |

其余任何位置的 `.mp3` / `.wav` 仍会被门禁拦下 —— 那是防「测试产物误入仓库」，不是防演示。
